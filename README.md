Proof of Peck (PECK) is a robotic woodpecker pecking working code out of a bounty board. This coin celebrates make.fun, where people and their AI agents enter paid competitions and their results are scored and ranked in public.
## Run it
```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
